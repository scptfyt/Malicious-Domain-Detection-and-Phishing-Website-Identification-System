基于深度学习的恶意域名检测与钓鱼网站识别系统 深度学习模型训练操作指南

说明：
本文件用于指导如何为当前毕设系统训练真正的深度学习模型。当前系统已经具备“字符 TF-IDF + 传统机器学习分类器”的本地基线训练流程，下一步要做的是准备真实数据集，并扩展 CNN、LSTM 或 BiLSTM 这类深度学习模型训练流程。

一、最终目标

训练一个可以接入当前 Web 系统的深度学习模型，使系统完成以下闭环：

1. 从网上获取正常域名、钓鱼 URL、恶意 URL 数据。
2. 清洗数据，统一生成训练 CSV。
3. 使用 PyTorch 在本机训练 CNN 或 BiLSTM 模型。
4. 输出 Accuracy、Precision、Recall、F1、AUC、混淆矩阵等指标。
5. 保存模型文件，例如 artifacts/models/deep_bilstm_v1.pt。
6. 将模型信息写入 MySQL 的 model_info 和 evaluation_metric 表。
7. 在系统“模型中心”启用深度学习模型。
8. 前端实时检测时调用该模型进行预测。

二、推荐训练路线

建议先按以下顺序做，不要一开始就做太复杂：

第一版：字符级 CNN
优点：训练快，对本机 CPU 也比较友好，适合先跑通深度学习训练。

第二版：字符级 BiLSTM
优点：更符合“字符序列建模”的论文表述，适合毕业设计答辩展示。

第三版：CNN + 统计特征混合模型
优点：可以作为系统创新点，对应“深度特征 + 人工统计特征融合”。

三、需要准备的软件环境

1. 打开 PowerShell。
2. 进入项目目录：

   cd /d E:\BIYESHEJI

   如果 PowerShell 不支持 cd /d，则执行：

   E:
   cd E:\BIYESHEJI

3. 确认 Python 版本：

   D:/Python/python3.11.3/python.exe --version

4. 确认项目依赖已经安装：

   D:/Python/python3.11.3/python.exe -m pip install -r E:/BIYESHEJI/requirements.txt

5. 安装 PyTorch。

   如果你的电脑没有 NVIDIA 显卡，或不确定有没有 CUDA，建议先安装 CPU 版本：

   D:/Python/python3.11.3/python.exe -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

   如果你有 NVIDIA 显卡，后续可以去 PyTorch 官网选择 Windows + Pip + Python + 对应 CUDA 版本，复制官网生成的安装命令。

6. 验证 PyTorch 是否安装成功：

   D:/Python/python3.11.3/python.exe -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"

   如果输出 torch 版本号，说明安装成功。
   如果 torch.cuda.is_available() 输出 False，也可以训练，只是会用 CPU，速度慢一些。

四、推荐下载的数据集

为了保证毕业设计合理，建议至少准备两类数据：正常域名和恶意/钓鱼 URL。

1. 正常域名数据

推荐来源 A：Tranco
官网：https://tranco-list.eu/
用途：下载热门正常域名排行榜，作为 benign 正常样本。
操作：
1. 打开 https://tranco-list.eu/
2. 找到“Download the latest Tranco list”或“Retrieve latest list”。
3. 下载 CSV 或 ZIP 文件。
4. 解压后通常是两列：排名、域名。
5. 取前 5000 到 50000 条即可，不建议一开始导入 100 万条。

推荐来源 B：Majestic Million
官网：https://majestic.com/reports/majestic-million
用途：同样作为正常域名样本。
操作：
1. 打开 https://majestic.com/reports/majestic-million
2. 点击 Export CSV。
3. 下载后提取 Domain 列。
4. 标签统一设置为 benign。

2. 钓鱼 URL 数据

推荐来源：PhishTank
官网：https://phishtank.org/developer_info.php
用途：下载 verified online phishing URL，作为 phishing 样本。
操作：
1. 打开 https://phishtank.org/developer_info.php
2. 找到 Get the Database。
3. 优先下载 CSV 格式，例如 online-valid.csv 或 online-valid.csv.gz。
4. 如果下载次数受限，注册 PhishTank 账号并申请 application key。
5. 只提取 url 列。
6. 标签统一设置为 phishing。

3. 恶意 URL 数据

推荐来源：URLhaus
官网：https://urlhaus.abuse.ch/
Feeds/API：https://urlhaus.abuse.ch/feeds/
用途：下载恶意软件传播 URL，作为 malware 或 malicious 样本。
操作：
1. 打开 https://urlhaus.abuse.ch/
2. 如果进入 Feeds 页面，需要注意该页面不是全量恶意 URL 下载入口，而是按 ASN、国家或 TLD 过滤生成数据。
3. 在 Feeds 页面中，ASN Feed 需要输入 AS 编号，Country Feed 需要输入国家代码，TLD Feed 需要输入顶级域名，例如 top、xyz、com，然后点击 Generate CSV 或 Generate JSON。
4. 如果想获取更完整的 URLhaus URL 数据，需要进入 Access Data 下的 API/Datasets 相关页面，通常需要登录并创建 Auth-Key。
5. 如果无法登录或注册，建议先使用 Kaggle 恶意 URL 数据集或 PhishTank 钓鱼 URL 数据集完成训练流程，URLhaus 可作为后续补充来源。
6. 只提取 URL 字符串，不要下载恶意样本文件。
7. 标签可设置为 malware 或 malicious。

4. 综合数据集

推荐来源：Kaggle Malicious URLs Dataset
地址：https://www.kaggle.com/datasets/sid321axn/malicious-urls-dataset
用途：快速获得 benign、phishing、malware、defacement 多类别 URL 数据。
操作：
1. 打开 Kaggle 页面。
2. 登录 Kaggle 账号。
3. 点击 Download。
4. 解压得到 CSV 文件。
5. 常见字段为 url/type 或 url/label。
6. 可将 benign 保持为 benign，其余 phishing、malware、defacement 统一作为恶意类，也可以保留多分类标签。

五、建议的数据目录结构

请在 E:\BIYESHEJI 下创建如下目录：

data
  raw
    tranco.csv
    majestic.csv
    phishtank.csv
    urlhaus.csv
    kaggle_malicious_urls.csv
  processed
    urls_train.csv
    urls_val.csv
    urls_test.csv
    char_vocab.json

说明：

1. raw 目录保存原始下载文件，不要直接修改。
2. processed 目录保存清洗后的训练文件。
3. 最终训练 CSV 建议统一为两列：

   url,label
   https://www.baidu.com,benign
   https://example-login.top/account,phishing

六、数据清洗规则

1. 删除空行。
2. 删除重复 URL。
3. 删除长度过短的数据，例如少于 4 个字符。
4. 删除明显不是域名或 URL 的内容。
5. 正常域名统一补成可训练文本即可，不一定必须加 http://。
6. 标签统一：
   benign -> 正常
   phishing -> 钓鱼
   malware -> 恶意软件传播
   defacement -> 篡改页面
   malicious -> 泛恶意
7. 二分类训练时：
   benign 记为 0
   非 benign 记为 1
8. 多分类训练时：
   benign、phishing、malware、defacement 分别设为不同类别。

七、推荐样本数量

为了顺利答辩，不建议样本太少。

入门版：
正常 2000 条
钓鱼/恶意 2000 条
总计 4000 条左右

推荐版：
正常 10000 条
钓鱼 5000 条
恶意 5000 条
总计 20000 条左右

论文实验版：
正常 30000 条
钓鱼 10000 条
恶意 10000 条
篡改 10000 条
总计 60000 条左右

如果电脑性能一般，先训练 4000 到 20000 条，不要一开始上 60 万条。

八、训练集划分

建议固定划分比例：

训练集：70%
验证集：15%
测试集：15%

或者：

训练集：80%
验证集：10%
测试集：10%

必须注意：

1. 同一个 URL 不应同时出现在训练集和测试集。
2. 正常和恶意样本要尽量保持比例合理。
3. 论文中要写明划分比例。

九、字符级深度学习模型输入设计

1. 将 URL 或域名转成小写。
2. 建立字符字典 char_vocab.json。
3. 每个字符映射为一个数字 ID。
4. 设置最大长度 max_len，建议 200 或 255。
5. 短 URL 用 0 padding。
6. 长 URL 截断到 max_len。
7. 模型输入形状为：

   batch_size x max_len

十、CNN 模型结构建议

适合第一版深度学习模型。

结构：

1. Embedding 层
2. 多个 Conv1D 卷积层，卷积核大小可设置为 3、4、5
3. ReLU 激活
4. MaxPooling
5. Dropout
6. 全连接层
7. Sigmoid 或 Softmax 输出

建议参数：

max_len = 200 或 255
embedding_dim = 64
num_filters = 128
kernel_sizes = [3, 4, 5]
dropout = 0.3
batch_size = 64
epochs = 5 到 15
learning_rate = 0.001

十一、BiLSTM 模型结构建议

适合第二版模型，也是论文中比较容易解释的深度学习模型。

结构：

1. Embedding 层
2. BiLSTM 层
3. Dropout
4. 全连接层
5. Sigmoid 或 Softmax 输出

建议参数：

max_len = 200 或 255
embedding_dim = 64
hidden_size = 128
num_layers = 1 或 2
dropout = 0.3
batch_size = 64
epochs = 5 到 15
learning_rate = 0.001

十四、论文中可以这样写

数据来源：
正常样本主要来自 Tranco 或 Majestic Million 热门域名列表，钓鱼样本来自 PhishTank verified online phishing URL 数据库，恶意 URL 样本来自 URLhaus 或公开 Kaggle 恶意 URL 数据集。

模型输入：
系统将 URL 统一转为小写字符序列，通过字符字典映射为整数序列，并进行固定长度截断或 padding。模型通过 Embedding 层学习字符向量表示。

模型结构：
本文设计字符级 CNN 与 BiLSTM 模型。CNN 用于提取局部字符组合特征，BiLSTM 用于捕获 URL 字符序列中的上下文依赖关系。

评估指标：
实验采用 Accuracy、Precision、Recall、F1、AUC 和混淆矩阵作为评价指标，并与字符 TF-IDF + 传统机器学习基线模型进行对比。

十五、注意事项

1. 不要下载 URLhaus 的恶意样本文件，只需要 URL 字符串。
2. 不要直接访问恶意 URL。
3. 下载数据集后只做文本分析，不要在浏览器中打开可疑链接。
4. 如果训练速度很慢，先减少样本数量和 epoch。
5. 如果模型指标接近 1.0，要检查是否数据泄露或数据过于简单。
6. 如果 Recall 很低，说明恶意样本漏报较多，需要增加恶意样本或调整类别权重。
7. 如果 Precision 很低，说明误报多，需要增加正常样本多样性。
