本地训练助手
模型训练已迁移到用户本地电脑完成。训练完成后，将本地生成的模型文件导入系统，即可在单条检测和批量检测中选择使用。
训练流程
  1. 下载训练助手并解压到本地固定目录。
  2. 运行一键安装脚本，安装依赖并注册本地训练协议。
  3. 打开训练助手，选择正常样本和恶意/钓鱼样本进行训练。
  4. 训练完成后，在本地目录查看模型文件和指标文件。
