76. 修复本地训练助手打开体验：前端 `domaintrainer://open` 调起逻辑改为根据页面失焦/可见性变化判断是否成功，避免程序已打开仍误报“未安装”；协议注册脚本改用 `reg.exe` 写入注册表默认值并新增 `install_protocol.cmd`；启动脚本增强 Python 路径检测；训练助手 README 改为中英双语；登录页系统名称调整字号和最大宽度，避免桌面端最后一个字孤立换行。
77. 修复本地训练助手“打开后迅速闪退”排查与启动稳定性：重写 `open_trainer.cmd`，启动时生成 `trainer_launch.log`，记录工作目录、Python 命令、错误输出和退出码，并在失败时暂停窗口；协议注册命令改为通过 `cmd.exe /c` 拉起批处理，提高 Windows URL Protocol 启动兼容性；README 补充直接双击启动和查看日志的排查说明。
78. 继续增强本地训练助手启动诊断：新增 `launch_trainer.py` 作为启动包装器，统一检查依赖、启动 GUI 主程序并在失败时弹窗提示；`open_trainer.cmd` 改为将日志写入 `%LOCALAPPDATA%\DomainTrainer\trainer_launch.log`，避免从网页协议启动时日志位置不明确；下载包接口已确认包含新启动包装器。
79. 修复本地训练助手安装脚本无输出和启动无日志的问题：将 `install_protocol.cmd` 改为纯批处理直接注册 `domaintrainer://` 协议并写入 `protocol_install.log`，避免依赖 PowerShell；将 `open_trainer.cmd` 改为纯 ASCII 输出并统一写入 `%LOCALAPPDATA%\DomainTrainer\trainer_launch.log`，避免中文编码导致批处理解析异常；README 同步更新日志位置和排查方式。
80. 修复本地训练助手因日志文件冲突导致的启动失败：`open_trainer.cmd` 不再将 Python 输出重定向到 `trainer_launch.log`，改为单独写入 `trainer_cmd.log`，避免与 `launch_trainer.py` 同时写同一日志文件造成 Windows 文件锁定；`launch_trainer.py` 增加日志后备路径，若 `%LOCALAPPDATA%` 不可写则回退到训练助手目录；README 同步补充两个日志文件的查看顺序。
81. 优化本地训练助手窗口和模型中心交互：本地训练助手默认窗口调整为 920x720，增加最小尺寸和指标表格高度/列宽，避免默认打开时看不清指标区；网页模型中心将“打开本地训练助手”设为主操作，“下载训练助手”为辅助操作，“网页内训练”弱化为本地服务专用入口，并将刷新按钮移至模型版本标题栏右侧，提升页面操作层级和视觉协调性。
82. 将模型中心改造为更适配本地训练场景的工作台：删除网页端训练表单、上传控件、网页内训练按钮和最新指标卡片，保留“打开本地训练助手”“下载训练助手”作为核心操作；新增本地训练流程说明卡片，模型版本保留刷新入口和列表展示，前端同步移除网页训练相关 JS 绑定与指标渲染逻辑，避免线上环境误导用户执行不可持久化训练。
83. 完成本地训练模型接入系统的闭环：模型表新增数据库存储字段，支持将本地训练助手生成的 `.joblib` 模型以账号私有方式导入数据库；后端新增 `/api/models/import-local` 接口并在检测时可从数据库加载模型；模型中心新增“导入本地训练模型”表单，导入后当前账号可在单条检测和批量检测中选择使用，其他普通用户不可见不可用，管理员仍可监管查看。
84. 修复模型启用状态显示与切换逻辑：普通用户模型列表改为按“个人启用模型优先，否则系统启用模型”的规则计算当前账号实际启用模型，避免导入个人模型后与系统默认模型同时显示“启用中”；模型管理中系统模型增加“启用”按钮但不允许删除，用户可在系统模型和个人导入模型之间切换；删除个人启用模型后不再误激活其他用户模型。
85. 优化模型管理切换速度：模型列表、模型启用、仪表盘当前模型和管理员用户模型明细等只需要展示元数据的接口改为延迟加载 `model_blob`，并调整模型序列化逻辑避免读取模型二进制字段；模型文件仅在实际检测预测时读取，从而减少云数据库传输大字段造成的等待。
86. 新增登录状态下修改密码功能：后端增加 `/api/auth/password` 接口，要求校验原密码、新密码长度和两次确认一致后重新生成密码哈希，并记录“修改密码”操作日志；前端侧边栏账号操作区新增“修改密码”入口，弹窗填写原密码、新密码和确认密码，成功后提示用户使用新密码登录。
